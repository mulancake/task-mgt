### Project Overview:
  Mini Task Manager app is a simple task tracking app where users can view, add, edit and delete tasks. It has also an additional functionality of marking the task as complete or incomplete.
### Tech stack used:
  I created the app via VS Code. 
  1. React 19 (with JSX)
  2. Vite (build tool & dev server)
  3. CSS (plain, no framework)
### Setup instructions:
  1. Install via VS code terminal. Run this command: `npm install`
### How to run the app:
  1. Go to the VS code terminal.
  2. Navigate to the tsk-mgt\frontend folder in the terminal.
  3. Type this command `npm run dev`.
  4. Copy the local url or `this http://localhost:5173/` and paste it in the browser.
### How to run tests:
  1. Click `New Task` button in the app to add a new task.
  2. Click `Edit Task` button to edit an existing task.
  3. Click `Delete` button to delete a task.
  4. Click `Complete`/`Incomplete` button to mark the task as complete or incomplete.
  5. Select filter values to apply filters.
### Any tradeoff, limitations or unfinished parts:
  1. I did not store the records in a database.
  2. I did not use any backend technologies.
  3. Tasks created disappear when browser is refreshed.
